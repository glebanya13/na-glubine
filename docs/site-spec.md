# Deep Dive Nights

Создай современный премиальный сайт для караоке-бара **«На Глубине»**.

### Информация о заведении

Название: **На Глубине**
Адрес: **Рождественская ул., с8**
Формат: караоке-бар / ресторан / ночное заведение.

Основная задача сайта — показать атмосферу заведения, вызвать желание прийти вечером и максимально упростить бронирование столика.

Сайт должен ощущаться как сайт современного московского караоке-клуба, а не как обычный ресторанный шаблон.

---

# ВИЗУАЛЬНЫЙ СТИЛЬ

Используй фотографии заведения как главный визуальный материал.

Стиль:

- premium nightlife;
- dark luxury;
- современная типографика;
- глубокий чёрный / графитовый фон;
- белая типографика;
- небольшие акцентные цвета из фотографий заведения;
- большие фотографии;
- много воздуха;
- плавные анимации;
- glass / blur элементы использовать умеренно;
- никаких дешёвых градиентов;
- никаких стоковых фотографий;
- никаких AI-generated фотографий вместо реальных фотографий заведения.

Сайт должен выглядеть дорого, атмосферно и немного дерзко.

# ФОТОГРАФИИ ЕДЫ

Используй фотографии еды из предоставленных материалов.

ВАЖНО:

Не генерируй фотографии блюд самостоятельно.

Используй реальные фотографии, предоставленные владельцем заведения.

Для каждой фотографии:

- сохрани оригинальное соотношение сторон;
- не растягивай изображение;
- используй object-fit: cover;
- сделай единый визуальный стиль карточек;
- фотографии должны быть крупными и аппетитными.

Если для конкретного блюда фотографии нет — НЕ придумывай фотографию. Используй аккуратный placeholder или карточку без изображения.

- Android;
- desktop;
- большие мониторы.

Используй:

- React;
- TypeScript;
- Tailwind CSS;
- современные компоненты;
- плавные CSS animations;
- lazy loading изображений;
- оптимизацию изображений.
